# 后端执行计划

版本3.1｜2026-11-10。规则唯一入口：[共享规则](06_跨组接口与状态规则.md)；门禁见[总计划](01_总计划与交付门禁.md)。

后端A负责设备链路，后端B负责数据与权限；不是两人各写半个同名模块。已有resp/db/models/auth/devices都增量修改。所有测试在隔离库，禁止import应用时顺手创建正式表。

## 1. 基线与交接

- 保留resp.py外壳、db.py连接设置、现有路由路径、models.py主键和msg_id。
- 待补link与services目前无核心实现，不把文档里的示例当运行基线。
- BA签署submit_motion/enqueue_trigger/snapshot_for；BB签署authorize_context/revoke_access；详见06§6。
- models和迁移由BB合入；main/run由BA合入；commands/events薄路由由BB合入并调用BA服务。
- CLI改授权前必须证明后端已停止；运行时改密/解绑/注销走同一SendGate。不要另写一条直接UPDATE的快速通道。
- 依赖清单当前不成立：backend/requirements.txt 现有 12 个包不含 alembic、argon2-cffi、pytest。BB01 增加 alembic 与 argon2-cffi 并更新锁定文件；BB00 单列开发依赖（pytest、pytest-asyncio、httpx 已在）。干净 Windows 环境装完后必须能跑迁移与测试，装不上就是依赖没写完。
- 测试骨架同样不存在：backend/ 下没有 tests/、没有 conftest.py、没有 pytest.ini。BB00 建 tests/conftest.py（隔离库 fixture、拒绝生产库名 pet_dog、SIM 串口默认值）与 tests/__init__ 约定；此后各卡新增测试文件直接放入。
- config.py 归 BB02 唯一合入（DB/时区/JWT/ACK/天气全部配置项），BA02 只读不写；任何一卡要加配置键先改本卡说明再改文件，禁止两卡各自加同名字段。

依赖判读：前置项中标注为“阶段产物（不要求整卡完成）”的卡号仅表示交接指引；检查整卡关键路径时不得据此建立对方整卡完成依赖，只有明确要求整卡完成的前置才形成该依赖。

**文件：** security.py/deps.py/auth.py/cli.py；tests/test_auth.py、test_admin.py

**按顺序做：**

4. 密码输入的终端判定必须写死五步，缺一条就会在管道下读到明文进程行为：① sys.stdin / sys.__stdin__ / sys.stderr 任一为 None 直接拒绝；② sys.stdin is not sys.__stdin__（被重定向）拒绝；③ not sys.stdin.isatty() 拒绝；④ warnings.simplefilter('error', getpass.GetPassWarning) 之后再调 getpass（Windows 上管道并不必然触发该警告，它只是兜底）；⑤ 两次读取施加同一保护并比对。isatty 是主判据，GetPassWarning 是兜底，不能只写 except。
